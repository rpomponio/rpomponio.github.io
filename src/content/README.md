# Content

This directory will become the source of truth for the site's content.

Suggested structure:

    science/
      hmpv.md
      neuroharmonize.md

    adventures/
      washington-pass-2025.md

    creative/
      west-virginia.md
      northern-mexico.md

Each Markdown file will contain frontmatter (structured metadata) followed
by ordinary Markdown prose. Astro content collections will validate the
frontmatter and generate the pages automatically.
